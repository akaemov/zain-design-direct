# Интерактивная стратегия Яндекс.Директ

Это готовый статический мини‑сайт с визуальной стратегией для клиента.

## Что внутри
- `index.html` — основная интерактивная страница;
- `assets/data.json` — данные проекта;
- сам сайт не использует внешние зависимости, поэтому его удобно публиковать как GitHub Pages / Netlify / Vercel.

## Как опубликовать в GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в него содержимое этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - Source: **Deploy from a branch**
   - Branch: `main` (или `master`)
   - Folder: `/root`
5. Сохраните настройки. Через 1–2 минуты GitHub Pages выдаст публичный URL.

## Возможные следующие улучшения
- добавить логотип и фирменные цвета клиента;
- подключить реальные кейсы и изображения интерьеров;
- встроить форму обратной связи;
- добавить отдельные страницы по ЖК;
- сделать англоязычную версию.

## Ограничение
Документ визуализирует стратегию и её логику, но не публикует репозиторий автоматически — для этого нужен доступ к вашему GitHub-аккаунту.
